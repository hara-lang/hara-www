title: Self Learning
---
Choose a book, a focused course, or a sequence of small problems. Each resource
opens into its own workspace so the sidebar contains only that material.

## Read

[The Little Book of HAL](../books/the-little-book-of-hal/docs/index.md) is a
compact narrative introduction to Hara.

## Study a system

[Protocols for Builders](../learn/protocols/index.md) develops the protocol
model through collections, state, lifecycle, and a practical protocol atlas.

## Practise

[Hara Koans](https://world.hara-lang.org/learn/koans/) is the interactive
problem set on Hara World. Solve problems in the browser, retain progress with
your Hara identity, and compare accepted solutions after completing a Koan.
